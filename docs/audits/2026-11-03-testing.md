## Summary for the owner
The tests are in good shape where it matters most for safety. I broke 13
important lines on purpose (who may change a list, private lists, signed-out
and expired sessions, deleting an account, likes, catalog paging) and the
tests caught every one that mattered. Every past bug fix I undid was caught
too, with one half-exception (TEST-13). 93% of the server code runs during
the tests, and the fake database is real SQLite with Cloudflare's own limits.
The tests pass reliably, including around clock changes and midnight.

What is wrong is mostly around the tests, not inside them:
- **Nothing stops red code reaching the live site** (TEST-04). 12 of the
  last 40 CI runs on `main` were red, including merged pull requests, and the
  deploy checklist never asks whether CI passed. This is one GitHub setting.
- **The backup file is not tested as a whole** (TEST-12). Right now every
  visitor is told to back up their data before the site closes. If a change
  dropped custom lists, channels or presets from that file, no test would
  notice, and people would find out only when restoring. The backup works
  today (I checked).
- **Some features have no test at all**: adding to or removing from
  Trakt/TMDB/Simkl/MDBList lists and syncing history to them (TEST-01), the
  Trakt history and MDBList watchlist rows in Stremio (TEST-10), the badged
  posters Stremio shows (TEST-03), and any real-browser walk through the site
  (TEST-08; I did one by hand and it worked).
- **The nightly provider check cries wolf** (TEST-05): red for 8 nights over a
  contract line stricter than the code. It also skips TMDB and Trakt because
  their keys are not set (TEST-06).
- Smaller: two speed checks flake under load (TEST-07), the suite quietly
  sends ~1,200 requests to real services per run (TEST-11), `verify.sh` and
  CI differ (TEST-09).

Fix first: turn on required checks (TEST-04), then the backup round-trip test
(TEST-12), because of the 8 November shutdown.

## Rules for the implementer
- Follow `CLAUDE.md`. Edit `src/**/NN_*.js`, never `worker_entry_combined.js`,
  then `python build.py`. No refactors or renames; one root cause per commit.
- For every bug: write the failing test first, then fix. The test must fail
  if the fix is reverted.
- After each item: `bash verify.sh -q --fast` plus the one test file. Before
  pushing: `bash verify.sh -q`. Run `python tools/gen_map.py` if functions
  were added, removed or moved.
- New route: add it to `tests/route-access.json`; admin routes check
  `isAdminRequest`.
- UI changes follow `docs/AI_UI_RULES.md`; run
  `node tests/ui-contract.mjs --update` only when the look changed on purpose.
- Never skip or loosen a test or guard to get green.
- Add a `docs/RELEASES.md` entry at the end.
- Testing findings: a new or strengthened test must be shown to fail against
  a deliberately broken copy of the code (mutation) before it is accepted.

### TEST-03 (Medium, Test Coverage, Confirmed): the badged poster JPEG that Stremio users see is never rendered in a test, and its failures are silent
**What a user would notice.** If the hand-written PNG/JPEG badge drawing
breaks, Stremio users get an SVG poster instead, which (per the code's own

**Evidence.** `src/api/71_poster-and-support-routes.js:467-473`:
`if (env && env.IMAGES && posterBytes) { try { return await renderBadgedPosterJpeg(...) } catch (e) {} }`
and the comment above it: "Stremio cannot draw an SVG". Coverage run:
`renderBadgedPosterJpeg`, `badgePngCrc`, `encodeBadgePng`, `badgeHexRgb`,

needs an `IMAGES` stub that nobody added, and the empty `catch` hides a break.

**Test.** Must fail if `encodeBadgePng` writes a wrong CRC or if the branch is

**What a user would notice.** Nothing directly. But a nightly alarm that is

**Evidence.** Provider live check runs 26-34 (2026-10-24 to 2026-11-01) all

check failing if JustWatch drops `newOffer` altogether.
**Test.** `tests/provider-contracts.test.mjs` already checks each fixture
against its own list; add a case to the path-checker tests there: an answer
whose first edge has no `newOffer` and whose second has one passes, and one

**Risk.** None.
